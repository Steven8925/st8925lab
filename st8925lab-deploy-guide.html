st8925lab.com 部署教學筆記

記錄本次部署 st8925lab.com 網站的完整流程，方便下次自己操作。架構：GitHub repo (Steven8925/st8925lab) → Cloudflare Workers（Git 整合，自動部署）→ 自訂網域 st8925lab.com。

一、從 PC 修改程式碼 push 到 GitHub 的流程

這是日後最常用的流程：只要在自己電腦修改網站檔案，push 上去，Cloudflare 就會自動重新部署，完全不需要手動操作 Cloudflare。

1. 第一次在電腦上取得專案（只需做一次）

git clone https://github.com/Steven8925/st8925lab.git
cd st8925lab

2. 修改網站檔案

用編輯器修改 index.html / app.js / geodata.js 等檔案並存檔。

3. 確認修改了哪些檔案

git status

4. 加入變更並提交

git add .
git commit -m "說明這次改了什麼"

5. 推送到 GitHub

git push origin main

push 成功後，Cloudflare 會自動偵測到 main 分支有新的 commit，開始自動建置與部署（大約幾十秒內完成），不需要再登入 Cloudflare 操作。

小提醒：如果不熟悉指令列，也可以直接在 GitHub 網頁上編輯檔案（Code → 點檔案 → 筆的圖示 → 編輯 → Commit changes），效果相同，一樣會觸發自動部署。

二、如果要從零開始建立一個新的 Worker（例如新專案）

  1. 登入 Cloudflare Dashboard → 左側選單 Workers & Pages。
  2. 右上角點 Create application。
  3. 選擇 Continue with GitHub（第一次會要求安裝並授權 Cloudflare 的 GitHub App，可選擇只授權特定 repo）。
  4. 在 Select a repository 畫面選擇要部署的 GitHub repo，按 Next。
  5. 在 Set up your application 畫面設定：
    • Project name：專案名稱（會成為預設網址的一部分）
    • Build command：純靜態網站（無 build 流程）留空即可
    • Deploy command：預設 npx wrangler deploy，靜態網站不需要更改
    • Advanced settings → Path：靜態檔案在 repo 根目錄就填 /，若檔案在子資料夾則填該路徑
  6. 按 Deploy，等待 Initializing → Cloning → Installing → Deploying 全部完成。
  7. 完成後會產生一個 *.workers.dev 的預設網址，可以先用這個網址測試網站是否正常。

三、綁定自訂網域（例如 st8925lab.com）

前提：這個網域必須已經加入同一個 Cloudflare 帳戶（在 Domains 底下可以看到）。

  1. 進入該 Worker 專案 → 上方分頁點 Domains。
  2. 點 Add Domain。
  3. 從清單選擇要綁定的網域（例如 st8925lab.com）。
  4. 子網域欄位：留空代表綁定根網域（st8925lab.com）；若要綁定 www，則在該欄位輸入 www。
  5. 點 Add domain，幾秒到幾分鐘內 SSL 憑證會自動簽發生效。
目前只綁定了根網域 st8925lab.com。如果之後想要 www.st8925lab.com 也能訪問，重複上面的步驟，子網域填 www 即可。

四、隱藏不想公開的資料夾／檔案（.assetsignore）

因為 Deploy 時沒有 wrangler.toml，Cloudflare 預設會把 repo 內所有檔案都當成公開靜態資源上傳。如果 repo 裡有不想公開的資料夾（例如企劃草稿 cloudmd/），可以加一個規則檔排除：

  1. 在 GitHub repo 根目錄新增檔案，命名為 .assetsignore
  2. 內容寫要排除的路徑，例如：
    cloudmd/
  3. Commit 到 main 分支，Cloudflare 會自動重新部署，該路徑之後就無法從網址直接存取。

五、目前 st8925lab.com 的實際設定摘要

  • GitHub repo：Steven8925/st8925lab（main 分支）
  • Cloudflare Worker 專案名稱：st8925lab
  • 部署方式：Git 整合自動部署（Build command 留空，Deploy command 為 npx wrangler deploy，Path 為 /）
  • 已綁定自訂網域：st8925lab.com（根網域）
  • 已排除公開的路徑：cloudmd/（透過 .assetsignore）
