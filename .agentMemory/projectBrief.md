# Project Brief: ST8925 LAB

## 1. Executive Summary
ST8925 LAB (https://st8925lab.com) is a high-performance, precision-engineered engineering showcase and multi-project platform. It features an interactive Canvas 2D / 3D night-Earth homepage with orbital simulation, unified navigation, and distinct standalone subprojects.

## 2. Core Architecture & Orbit Projects
The portfolio orchestrates six distinct projects mapped onto orbital rings with dynamic nebula burst transitions and bi-directional linking:
- **01: alarm-notification-simulator**: Industrial alarm generation, notification dispatch, and acknowledgment simulator.
- **02: iot-gen2-simulator-monitor**: Wayne IoT Server Gen 2 simulator, monitor console, and production VPS architecture blueprint.
- **03: ai-diagnostic-kb**: Industrial chiller and cooling water AI diagnostic system and knowledge base platform.
- **04: project-04**: Independent standalone project sub-application.
- **05: project-05**: Independent standalone project sub-application.
- **06: Travel-Assistance**: "Brother Dou-You (AI 旅遊助手 豆油哥)" — dynamic AI travel itinerary and feasibility planning platform.

## 3. Platform Invariants
- **Single Source of Truth**: All project configurations, slugs, labels, and palettes are governed by `config.js`.
- **Palette Integrity**: 12 distinct rainbow hues guaranteed to have >= 7.26 contrast against the cyber dark background.
- **Offline & Verification First**: Root test suite `verify.py` validates geometry, color contrast, wordmark integrity, and scalability across 13 distinct audit categories.
- **Strict Git Submodule Architecture**: `Travel-Assistance` is maintained as a dedicated submodule linked to `https://github.com/Steven8925/Travel-Assistance`.
